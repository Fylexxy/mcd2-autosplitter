# mcd2-autosplitter

LiveSplit autosplitter and load remover for Minecraft Dungeons II on PC (Steam or Xbox app).

**Download:** [MCD2-Autosplitter-0.2.zip](https://github.com/Fylexxy/mcd2-autosplitter/raw/main/MCD2-Autosplitter-0.2.zip)

Setup steps are in `guide.txt` inside the zip.

what it does:
- timer starts when you load into the world from the menu
- loading screens pause the game time
- splits every time you finish a relevant main quest
- reset and the last split you do yourself

It only reads the game's memory, no mods or anything needed.

Still a test version. Xbox app should work but isn't tested yet.

If something breaks please dm "Fylexxy" on discord.
